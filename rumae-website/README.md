# RUMAE — Website Company Profile

Website company profile UMKM lilin aromaterapi RUMAE, dibuat menggunakan HTML, CSS, dan JavaScript murni.

## Cara menjalankan
1. Ekstrak folder project.
2. Buka `index.html` di browser, atau gunakan ekstensi Live Server di Visual Studio Code.
3. Pastikan koneksi internet tersedia untuk memuat Google Fonts dan foto dari Unsplash.

## Struktur file
- `index.html` — struktur halaman dan konten
- `style.css` — desain, layout, dan responsive styling
- `script.js` — navigasi mobile, filter produk, tombol kembali ke atas, dan tahun otomatis

## Bagian website
Home, About, Product/Service, Gallery, Contact.

## Fitur JavaScript
- Mobile navigation
- Filter produk berdasarkan kategori
- Tombol back-to-top
- Tahun copyright otomatis
